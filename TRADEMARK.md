# NazoOS Trademark Policy

The software in this repository is free software. You may use, study, modify and redistribute it under the licenses listed in [`LICENSES/`](LICENSES/). This policy does **not** limit any of those rights.

It only covers the **name "NazoOS" and the NazoOS logo** (the "Marks"). Their purpose is simple: users should be able to tell whether a system really comes from the NazoOS project.

The Marks are not registered. This document describes how the project asks them to be used.

## What the Marks are

- The name "NazoOS" and confusingly similar names
- The NazoOS logo and other artwork shipped in the `nazoos-branding` package
- The package prefix `nazoos-` when used for packages published as official NazoOS packages

## Allowed without asking

- Referring to NazoOS in articles, reviews, videos, tutorials, talks and forum posts
- Redistributing **unmodified** official NazoOS images and packages under the name NazoOS
- Stating facts about a derived work, e.g. "based on NazoOS" or "a fork of NazoOS"
- Using the logo to link to the project website or repository
- Using the Marks for personal, non-public builds

## Not allowed without permission

- Distributing **modified** images, packages or repositories under the name "NazoOS"
- Using the Marks in a way that suggests the project endorses, sponsors or supports your product, service or fork
- Using the Marks, or confusingly similar names, as part of a different product or distribution name
- Altering the logo and presenting the result as an official NazoOS logo

## Forks and derived distributions

You are welcome to fork NazoOS. If you publish a modified build:

1. Choose a different name.
2. Replace or remove the `nazoos-branding` package (logo, Plymouth theme, GRUB theme, wallpapers, `os-release`).
3. Do not use the official NazoOS OBS repositories as if they were your own update channel.

Packages can keep the `nazoos-` prefix internally where renaming would be impractical, as long as users are not misled about the origin of the system.
